# Episode Scripts

Shootable, word-for-word scripts for the *Present* channel
(see `docs/CHANNEL_PLAN.md`). Conventions used in every script:

- **[SAY]** — read aloud (your wording can drift; keep the *shape*).
- **[CUE]** — visual/audio action (timer, chime, scene note).
- **[BED]** — the exact NeuroTune command that generates that episode's audio.
- **(alt)** — swappable lines so repeat episodes don't feel copy-pasted.

House rules baked into all scripts (do not cut):
1. Never claim treatment/cure — we say "focus", "calm", "company", never "therapy".
2. State the mic plan out loud once, early ("I'll be quiet during the block") —
   silence must never feel like a malfunction.
3. One small win is the bar. We praise *showing up*, not output.
4. Breaks are same-shaped every episode: stand → water → one breath → back.
5. Captions on; no flashing; chimes are soft (the audio engine enforces gentle
   dynamics — keep your voice the same).
