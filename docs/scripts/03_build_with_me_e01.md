# 03 — Build With Me, Episode 1: "Ship Something Small" (45–60 min)

Code-along *presence*, not a tutorial. The viewer works on THEIR project beside
you; your narration is ambient, optional, skippable. Episode 1 is meta in the
best way: **we build a feature of NeuroTune itself** — the thing generating the
music they're hearing.

**[BED]** `python -m neurotune --mood steady_focus --minutes 60 --seed 301 --wav build_bed.wav`
**[CUE]** Screen capture of editor + terminal, your cam small in a corner.
Font size LARGE (mobile viewers). Captions on.

---

## COLD OPEN — 0:00–0:25

[SAY] "Tonight we ship one small thing, start to finish. The rule of this series:
it has to run before we stop. Not perfect — running. If you've got your own
project, open it now; you build yours, I'll build mine, and we'll keep each other
in the chair."

## THE PLAN — 0:25–2:00

[SAY] "Mine tonight: the music you're hearing right now is generated by a little
Python project. I'm adding one feature to it — [PICK ONE, e.g. 'a thumbnail
generator' / 'a new calm preset' / 'the metadata writer from the spec']. One
outcome, written down: by the end, `python -m neurotune [the new flag]` runs."

[SAY] "Write yours the same way — one sentence with the word 'runs' or 'done' in
it. That sentence is the whole spec. Okay — building."

## WORK PASSES — 2:00–~45:00 (three passes, ~12 min each)

[CUE] Narrate at ~10% density: one calm sentence every minute or two, in a
thinking-out-loud register. NEVER lecture. Long quiet stretches of typing are
correct.

Narration register examples:
- "Okay — test first, so I know what done looks like."
- "That's wrong. Good. Wrong fast is the cheap kind of wrong."
- "I'm naming this badly on purpose and moving on. Naming is a break-time
  problem."
- (when stuck, once per episode:) "I'm stuck, so I'm going to do the dumbest
  version that could work. The dumb version usually tells me what the smart
  version is."

[CUE] Between passes, a 60-second check-in — look at cam:

[SAY] "Pass one down. Where are you at? If you haven't typed anything yet,
that's allowed — open the file. Just the file. That's pass two's whole job."

## THE SHIP MOMENT — ~45:00–50:00

[CUE] Run it. Show it working — in episode 1's case, *play ten seconds of a
track the new code just produced*. React honestly (small smile beats fake hype).

[SAY] "It runs. That's the bar and we're over it. Commit message, push... done.
It's janky in two places and I'm leaving them janky until next week — shipped
beats polished, tonight and most nights."

## OUTRO — 50:00–52:00

[SAY] "Your turn: drop one line — what did you ship, or what's the file you're
opening tomorrow? Smallest answer wins. Next week: [NEXT FEATURE]. Bring the
next small thing."
